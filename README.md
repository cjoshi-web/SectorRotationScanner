# Ultimate ETF Scanner (23 Filters + RRG)

This is a Streamlit web application that scans over 50 Indian ETFs using 23 technical filters, RRG (Relative Rotation Graph) analysis, and provides a downloadable Excel report.

## Features
- Scans 50+ ETFs with Nifty 50 as benchmark.
- 23 unique filters covering Trend, Momentum, Structure, Volume, and Reversal.
- RRG Chart grouped by Macro Sectors.
- Downloadable Excel report with full ranking.

## How to Run Locally
1. Clone this repo.
2. Install dependencies: `pip install -r requirements.txt`
3. Run the app: `streamlit run app.py`
